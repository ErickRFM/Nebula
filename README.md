# NÉBULA Music

Plataforma musical multiplataforma con Next.js, React y TypeScript.

> Proyecto en fase de fundación. La biblioteca y el reproductor comercial todavía no están implementados. El catálogo musical estará restringido a archivos propios o contenido autorizado.

## Trabajo en desarrollo

Arquitectura web-first con diseño Cosmic Glass y preparación para Android/iOS mediante Capacitor. Consulta los Pull Requests antes de utilizar la aplicación.
