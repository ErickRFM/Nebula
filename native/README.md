# Native Party Sound integration notes

These are **unbuilt native source adapters**, not signed Android/iOS releases. They must be copied and registered in native projects generated by Capacitor; native builds and physical tests are not available in this session.

## Android
- `npx cap add android`, then `npm run mobile:sync` with Android SDK installed.
- Place `NebulaPartyPlugin.kt` and `NebulaPlaybackService.kt` in package `com.nebula.music`, register `NebulaPartyPlugin` in `MainActivity` before `super.onCreate`.
- Gradle: `androidx.media3:media3-exoplayer:1.11.1` and `androidx.media3:media3-session:1.11.1`.
- Manifest: INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE, FOREGROUND_SERVICE, FOREGROUND_SERVICE_MEDIA_PLAYBACK; notification/local-network permissions as applicable to API level.
- Register the service with `android:foregroundServiceType="mediaPlayback"` and `androidx.media3.session.MediaSessionService` intent action.
- Verify Android 17 local network permission model and hardware audio focus; no APK or media-session behavior is certified.

## iOS
- `npx cap add ios` on macOS/Xcode, register `NebulaPartyPlugin` in custom CAPBridgeViewController.
- Info.plist: `NSLocalNetworkUsageDescription`, `NSBonjourServices` containing `_nebula-room._tcp`; `UIBackgroundModes` audio only when authorized and tested.
- AVFoundation playback requires real background, interruption and AirPlay tests before release.

The caller must obtain an authorized HTTPS track URL and invoke playback **after a local user gesture**. Web playback is still the active production path. Native Bonjour/NSD scanning is implemented, but no local beacon advertises NÉBULA services yet; Google Cast and multi-output routing remain outstanding.
