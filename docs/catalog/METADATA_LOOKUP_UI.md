# C02.1: búsqueda visual de metadatos MusicBrainz

En Explorar, tras iniciar sesión, se ofrece una sección para buscar títulos/artistas/álbumes. Consulta el endpoint autenticado `/v1/metadata/musicbrainz`. Los resultados muestran grabación, artista, álbum y enlace de revisión.

**No** se cambia ninguna etiqueta de canciones importadas, ni se descarga audio o carátulas. En la siguiente etapa (una vez completado el catálogo musical privado) se implementará coincidencia asistida, revisión y aplicación confirmada de metadatos.
