# NÉBULA · Roadmap

- **F00 (design/spec)**: product boundaries, visual UI concepts, licensing policy. Design approved conceptually; rights handling still requires implementation and legal review.
- **F01 (this PR)**: reproducible Next.js workspace, React Cosmic Glass shell, seven navigable areas, functional in-browser local audio, typed queue rules, tests and CI.
- **F02 local**: persistent browser library, editable playlists and responsive E2E QA (delivered).
- **F03 API foundation**: Fastify, PostgreSQL, schema, account registration/login, bearer JWT and per-user playlist CRUD (in development). Cloud uploads, metadata worker and streaming authorization remain F04.
- **F04**: native Capacitor Android/iOS adapters; background playback and Bluetooth physical QA.
- **F05**: secure offline downloads, device control and listening rooms; rights enforcement mandatory.

No backend, licensed catalog, server sync, real rooms or native playback exists in F01.
